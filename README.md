# มองบล็อกหกด้าน

สื่อฝึกมองรูปทรงลูกบาศก์ (ขาว / เทา / ดำ) จากทั้งหกด้าน สำหรับชั้นประถม

**เปิดใช้งาน:** https://golufu.github.io/block-views/

- โจทย์สำเร็จรูป 18 ข้อ แบ่ง 3 ระดับ พร้อมเครื่องมือสร้างโจทย์เอง
- หมุนรูปทรงดูได้ทุกด้าน ระบายสีตอบในตาราง แล้วตรวจคำตอบทีละช่อง
- แจกโจทย์ให้นักเรียนด้วย "รหัสโจทย์" สั้น ๆ โดยไม่ต้องส่งไฟล์

## โครงสร้าง

`index.html` เป็นไฟล์เดียวจบ ไม่มี dependency นอกจากฟอนต์จาก Google Fonts
(ออฟไลน์ก็ใช้ได้ เพียงแต่จะเปลี่ยนไปใช้ฟอนต์ระบบ)

แก้ไฟล์แล้ว `git push` ได้เลย GitHub Pages จะ deploy ให้เองภายในราว 1 นาที
